# stolleautomation.com

Static "Coming Soon" marketing site for **NetPulse** — a macOS network monitor by Stolle Automation.

- Single self-contained page: `index.html` (inline CSS/JS, Google Fonts, SVG only — no build step).
- `CNAME` binds GitHub Pages to the apex domain `stolleautomation.com`.
- Served via **GitHub Pages**. DNS stays at GoDaddy; only the website records point here.

**This repo is public (GitHub Pages requirement). Keep it minimal — no business docs, no app code.**
The NetPulse app and all business/pricing/LLC docs live in a separate **private** repo.

To update the page: edit `index.html`, commit, push. Pages redeploys automatically.
